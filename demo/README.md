# Echoloom — Product Demo

**[Watch the character workflow demo](./Echoloom_Character_Marketplace_Demo.mp4)**

Mobile walkthrough of the current app:

1. Create an original character (Kael Ashford), including their profile and portrait.
2. Open **My Characters** and edit the character.
3. Publish the character to Marketplace and view the public listing.
4. Update the published listing and save a new revision.
5. Open **My Stories** to select two *private* characters and set up a scene.

**Recording notes:** This walkthrough was captured from the actual running app in an isolated, temporary test environment. AI profile/portrait generation uses deterministic demo fixtures, not live generative services; character, listing, and scene operations use the application's working frontend and API. Marketplace-owned character casting, paid story checkout and Web3 settlement are **not shown in this earlier recording**. The current code includes these workflows; live payment acceptance is still pending. For the newer prepared checkout scenario, see [Demo Environment](../docs/DEMO_ENVIRONMENT.md).

This folder stores the video itself in the repository, instead of depending on short-lived CI artifacts.
