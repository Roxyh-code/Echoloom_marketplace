# Intelligent Character Research
Firecrawl Agent autonomously discovers public fictional-character lore. No URL input. Existing LLM identifies a public fictional character, then Firecrawl gets structured facts and reported references. The profile generator honors the user description over lore. Portrait uses the enriched profile; voice matching is unchanged. Original/unclear characters and provider errors fall back to existing generation.

Enable after migration 0014: set FIRECRAWL_ENABLED=true and FIRECRAWL_API_KEY in ignored .env. Default budget 100 credits/run, 90-second polling deadline (network and cancellation can extend it), 5 attempted runs/account and 20 globally/UTC day (single server). Cancellation is best effort. Exact identity/era cache lasts up to 24 hours in one process. Paid attempts recorded in creation jobs; no automatic second run after ambiguous result. Classifier should emit only public identifiers; it and synthesis use the configured LLM. Signed-in user required for paid research. References are agent-reported, not independently fact-checked; research is not proof of commercial rights. Sources stay in private character data. Full source verification, durable shared cache and timeline-aware knowledge gates are future work. CI mocked; live API and browser acceptance pending.

Official API: https://docs.firecrawl.dev/api-reference/endpoint/agent
