# Nonblocking research
Creation saves a baseline profile before starting research, with the portrait and research workers independent. Research first identifies public fictional identity, checks the existing cache and daily budget, discovers up to three search/scrape sources, then uses Firecrawl Agent to synthesize evidence. Search excerpts are untrusted hints, not facts. The owner sees concise progress and an optional update with source references. Applying is explicit, checks the original profile version, preserves initial name/appearance/style, and creates a new revision; existing stories remain pinned. No migration. This is still a single-process prototype: a restart interrupts research, and no automatic paid retry is attempted. Cache remains process-local. Search consumes additional credits; the agent cap is unchanged. First usable profile no longer waits for either Firecrawl call; real API latency not measured.
Portrait failures show an original generic illustrated placeholder, not a likeness or a generated portrait. Provider moderation stays intact; review/edit is explicit. No automatic reformulation or alternate-provider retry to circumvent a safety decision.
