# Creator payout onboarding

Devnet demo opt-in: set SOLANA_CREATOR_SELF_SERVICE_ENABLED=true in local .env and restart FastAPI. Default false; only already approved creators may set up without the flag. Never enable this flag in a production approval environment. No deployment or chain transaction is required for setup. From publishing, select Set up earnings, connect and sign the payout-specific challenge (not a buyer binding). Return, tick Enable earnings for this character, and publish/save. Each listing gets an immutable revision with the verified payout wallet. An unchanged request is idempotent; edits preserve existing enablement unless explicitly disabled. Unpublish still disables. Existing pre-activation scene revisions must be recast. Buyer identity remains separate; same wallet cannot buy when it receives a payout. Payout wallet rotation is deliberately not supported. Devnet payment availability still depends on deployment readiness. No migration. Test: pytest tests/mvp/test_payment_creator_onboarding.py -v.
