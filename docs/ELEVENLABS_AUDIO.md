# ElevenLabs story audio (hackathon MVP)

Set ELEVENLABS_API_KEY and distinct ELEVENLABS_VOICE_A / ELEVENLABS_VOICE_B IDs from your authorized ElevenLabs catalog in .env. Optional ELEVENLABS_VOICE_NARRATOR, model defaults to eleven_multilingual_v2. Restart backend. In a normal scene reveal a passage and tap Listen. Different cast slots use different voices. Stop or navigate away to cancel playback. No voice cloning, no extra story allowance consumed. Text is sent to ElevenLabs only on explicit playback, from the server-authorized revealed prefix. The API key remains server-side. Bounded per-process cache and hourly request limit. No live provider acceptance yet. This MVP maps voices by cast slot, not persistent per-character voice selection; continuous full-scene audio is future work. Official API: https://elevenlabs.io/docs/api-reference/text-to-speech/convert
