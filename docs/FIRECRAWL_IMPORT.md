# Firecrawl character source import (hackathon MVP)

Set FIRECRAWL_API_KEY in the backend .env and restart. Sign in, open Create Character, expand Import character from a website, enter a character name and public HTTPS URL, confirm permission, then review the extracted source and choose Use imported description. Existing profile/portrait generation uses the imported description as input; it still requires configured model credentials. The user can edit before creation. Source URL is included in the saved original description, not a separate structured citation field. This MVP extracts bounded Markdown, not a fact-by-fact verified character schema. No automatic publication or monetization; separate rights confirmation still required. No local user-URL fetch, only Firecrawl's fixed v2 endpoint; do not submit private or credential-bearing URLs. Provider redirects and public-address checks are delegated to Firecrawl. Hourly request limit is process-local. Live provider test pending. API reference: https://docs.firecrawl.dev/api-reference/endpoint/scrape
