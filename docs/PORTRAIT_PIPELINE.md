# Portrait generation
Initial and subsequent new portraits use one task-scoped prompt from the committed Profile name, style and appearance. Narrative, research, private history and voice fields are not image input. Edits preserve explicit visual instructions. Profile is saved before image generation begins; voice selection remains available while portrait renders. Provider moderation remains enabled; no automatic rewriting or retry of rejected requests. User reviews visual requirements and explicitly requests a new portrait. No guarantee a particular portrait will be accepted. Private details link to Studio, owner-only status restores initial failure after reload and handles interrupted single-process jobs. No migration. CI and live provider validation pending.
