# GitHub profile README — installation

GitHub only shows a profile README after you create a **public repository whose name exactly matches your GitHub username**.

For this account the repository must be:

`https://github.com/Roxyh-code/Roxyh-code`

## One-time setup

1. On GitHub, create a **new public repository** called `Roxyh-code` under account `Roxyh-code`. Check **Add a README file**.
2. Open [this prepared profile README](README.md) and copy its full contents.
3. Edit `README.md` in the new `Roxyh-code/Roxyh-code` repository, replace its content and commit the change.
4. Open [your profile](https://github.com/Roxyh-code) to see the result.

No image files need to be copied manually: the template references existing image assets in public project repositories using absolute `raw.githubusercontent.com` URLs.
